# FLOPPI Security Core 1.3.1 — Remediation Matrix

**Estado:** autorización recibida; varios controles locales implementados; RLS/TLS y validación de staging pendientes.  
**Convenciones:** archivos indicados son superficies evidenciadas para revisar, no confirmación de que todos deban modificarse.

| Módulo | Estado local |
|---|---|
| Environment / Authentication | Implementado; `APP_ENV` explícito, token Supabase validado y errores fail-closed. |
| Administrator RBAC / API | Implementado para superficies operativas; rol solo en `app_metadata`; mutaciones admin emiten evento de autorización. |
| UI / secrets | SDK bundled, token bearer, `sessionStorage`; bundle servido y sin clave service role. Login real Supabase pendiente. |
| Worker security | Expiración obligatoria en código; migration 017 revoca credenciales legacy sin vencimiento; payloads de error redactados. Staging pendiente. |
| TLS / network | Compose limita binding a loopback; TLS/proxy/rate limit externo pendiente. |
| RLS / dependency / final audit | Solo revisión estática local y npm audit. Verificación real de Supabase, advisory Python y auditoría independiente pendientes. |

## 1. Decisión sobre migraciones

No se prescribe ahora una migración nueva. El hallazgo primario es de configuración/autorización y el rol administrativo recomendado puede residir en metadata confiable de Supabase Auth. Antes de decidir SQL, revisar permisos desplegados y si el registro actual satisface los requisitos de auditoría. Si aparece una brecha concreta, definir migration number, DDL, RLS, grants de cada rol, pruebas de aislamiento, rollback y compatibilidad en un documento revisado antes de implementarla.

Las migraciones 008 y 009 no están en este checkout según el README; no crear placeholders para ellas. El README enumera el orden solo hasta 015, mientras el checkout ya contiene 016; reconciliar esas instrucciones antes del siguiente paquete/deploy, sin cambiar la secuencia aplicada: [README.md](../README.md#L169-L175), [016_hybrid_signal_history.sql](../database/migrations/016_hybrid_signal_history.sql).
