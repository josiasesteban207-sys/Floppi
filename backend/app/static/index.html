GUÍA DE CONEXIÓN

Conectar un nodo

Señal de actividad saliente
  1. Genera una credencial única

    Ejecuta python tools\provision_worker.py --node-id blacki --expires-in-days 90 desde la carpeta de tu proyecto.

  2. Registra su hash en Supabase

    Aplica el SQL generado en el editor SQL de Supabase. Mantén privado el token original.

  3. Inicia el nodo localmente
    $env:FLOPPI_API_URL = "http://127.0.0.1:8000"
$env:FLOPPI_NODE_ID = "blacki"
$env:FLOPPI_NODE_TOKEN = "YOUR_PRIVATE_TOKEN"
python worker\local_worker.py

Para nodos remotos, utiliza una URL HTTPS de la API. No expongas públicamente la API ni el token.
